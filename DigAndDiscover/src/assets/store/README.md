# Store art overrides

Drop a PNG here named after the store item id and it replaces the placeholder
(or painted) icon automatically. Square images (256x256) look best.

Item ids live in `src/data/store.ts`, for example:

- `tool-iron-shovel.png`, `tool-steel-shovel.png`, `tool-gold-shovel.png`
- `tool-hand-axe.png`, `tool-pickaxe.png`, `tool-jackhammer.png`, `tool-drill.png`
- `tool-scanner.png`, `tool-deep-scanner.png`
- `tool-placeholder-1.png` ... `tool-placeholder-6.png`
- `up-stamina-tank.png`, `up-dig-damage.png`, ...
